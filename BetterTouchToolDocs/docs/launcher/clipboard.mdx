# Clipboard Manager in the Launcher

The Launcher contains a full-featured clipboard manager as a **rich surface**. In the main results list the Clipboard appears as a single entry; pressing `↩` on it expands the Launcher into the clipboard surface.

The clipboard surface reuses the data and transformers of the classic BTT [Clipboard Manager](../actions/clipboard-manager), so every clipboard entry from either view is the same.

## Opening the Clipboard

You can open the clipboard surface in several ways:

1. Type `clipboard` (or any custom alias you assigned) in the Launcher and press `↩`.
2. Use one of the **Paste Item 1/2/3** quick commands (`⌘1`–`⌘3`) on the Clipboard row to paste recent entries without expanding the surface.
3. Pin the Clipboard entry so it appears in the top-row pills of the Launcher.

## Layout

The surface is a two-pane layout:

- **Sidebar** — filter scopes such as *All*, *Text*, *URLs*, *Images*, *Files*, etc.
- **List** — all clipboard entries in the selected scope, newest first.
- **Preview** — on the right side, showing a preview of the selected item.

Row rendering is tuned for speed: list items are lightweight; heavy previews (PDFs, videos, office documents) load only when the item is selected.

## What You Can Do With an Entry

- **Preview** all common data types: text, rich text, images, PDFs, videos, office documents, URL previews.
- **Edit text entries** inline and save with `⌘S`.
- **Copy back to the clipboard** or **paste directly**.
- **Save as file** — export the entry to disk.
- **Apply text transformers** — including any [custom JavaScript transformers](../actions/text-transformer) you have configured.
- **Annotate images** — use the built-in markup tool to draw on screenshots before pasting.
- **Favorite** — keep snippets forever, independent of your clipboard history limit.
- **Search** — the search field at the top filters the list.

## Keyboard Shortcuts Inside the Clipboard

The standard macOS edit-menu shortcuts all work because the Launcher installs a temporary main menu while the clipboard surface is active.

| Key | Behavior |
| --- | --- |
| `↑` / `↓` | Move between clipboard entries. |
| `↩` | Paste the selected entry to the previously focused app. |
| `⌘C` | Copy the selected entry back to the system clipboard. |
| `⌘S` | Save inline text edits. |
| `Space` | Quick Look preview where applicable. |
| `Esc` | Leave the clipboard surface and return to normal results. |

## Quick Paste Without Opening

The Clipboard row in the main results list exposes three quick commands via the per-item actions popover (`⌘P`):

- `⌘1` — Paste Item 1
- `⌘2` — Paste Item 2
- `⌘3` — Paste Item 3

These shortcuts also work **directly** on the main results list when the Clipboard row is selected, so you can chain them into one keystroke: open Launcher → `⌘1`.

## Data and Privacy

Everything stays on your Mac. The clipboard history is not synced to any cloud service.

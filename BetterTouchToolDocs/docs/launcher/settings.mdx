# Theme & Settings

The Launcher has a menu button in the **top-left corner** of its window that opens both appearance controls and the full settings sheet.

## Appearance

Directly in the menu you can change:

- **Dark mode override** — *Always Use Dark Mode* forces dark styling regardless of the system setting.
- **Theme color** — choose from several preset accent colors. The selection is indicated by a colored dot next to the active option.

Appearance changes apply to all Launcher instances.

## Launcher Settings Sheet

The **Launcher Settings…** menu item opens a settings sheet with sections for:

### Groups

- Create, rename, and reorder groups (folders).
- Change each group's SF Symbol icon.
- Assign a **keyboard shortcut** to a group that jumps the Launcher directly to it.

### Built-In Sections

- Enable / disable each built-in section.
- Reorder sections by dragging.
- Assign a section to a group or remove it from its group.

See [Built-In Items](./built-in-items) for the full list.

### File Search

- Customize the file-search **keywords** (default: `file`).
- Add or remove **scope folders** that are searched first.
- Set the **maximum number of results**.
- Enable or disable the **broader Spotlight fallback** when scope results are empty.

### AI Limits

When h@llo.AI assistants are configured, the settings sheet also exposes limits for how many AI chat conversations are shown in the Launcher.

### Per-Item Customizations

Aliases, priorities, and hidden-state overrides edited via the per-item popover are listed here so you can review or reset them without hunting through the results.

## Reset

Most settings can be reset to defaults from inside each section of the settings sheet. Pinned items, aliases, priorities, and hidden states are all tracked separately, so you can reset one category without losing the others.

## Multiple Launcher Instances

Some settings (window position, pinned items, per-item overrides, query memory) are **per Launcher ID**. Others (theme, appearance) are global. See [Multiple Launchers](./multiple-launchers) for the full model.

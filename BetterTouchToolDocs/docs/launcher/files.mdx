# Files in the Launcher

The Launcher offers two separate ways to work with files:

1. **File Search** — a flat, fast, search-by-name experience.
2. **File Browser** — a Finder-like rich surface for navigating folders.

## File Search

File Search is a built-in section that returns indexed file results by name.

### Triggering File Search

File Search is *scoped*: it only activates when you explicitly ask for it, to keep normal launcher queries fast. You can trigger it by:

- Typing a **leading space** followed by the filename — e.g. ` report.pdf`.
- Typing the configured **file search keyword** (default: `file`), then a space, then your query — e.g. `file report`.

Both triggers can be enabled/disabled and the keyword is configurable in the Launcher settings.

### Search Scopes

In the Launcher settings you can:

- Specify **scope folders** that are searched first (e.g. `~/Documents`, `~/Downloads`, project folders).
- Limit the **max result count** per query.
- Enable a **fallback to broader Spotlight-style search** if the scope returns nothing.

### Per-Row Commands

File Search rows expose these commands (see also [Keyboard & Shortcuts](./keyboard-shortcuts)):

- **Quick Look** — `Space`
- **Reveal in Finder** — `⌘R`
- **Open Containing Folder** — `⌘⌥R`
- **Copy Path** — `⌘⇧C`

## File Browser

The File Browser is a **rich surface**: selecting the **File Browser** row expands the Launcher into a Finder-like pane.

### Browsing

- Arrow keys navigate between items.
- `↩` opens the selected item (folder → enter, file → open with default app).
- `←` / `Backspace` goes up a directory.
- `Space` opens a Quick Look preview.
- Typing filters the current folder.

### Drag and Drop

You can drag files into and out of the browser. Dragging files *onto* the Launcher's search bar pins them to the **drawer shelf** — a quick-access bar of files that appears below the search bar.

### Quick Look Preview

The surface uses the managed Quick Look coordinator, so previews behave exactly like in Finder: you can cycle through multiple selected files, and toggle fullscreen.

## Drawer Shelf

The drawer shelf is a bar that appears just below the Launcher's search field and holds files you've recently interacted with or dragged in.

- Drag a file from Finder or from the File Browser onto the Launcher to add it.
- Click a pill in the drawer shelf to open the file.
- Drag a pill away to remove it from the shelf.
- Files in the shelf persist across Launcher restarts.

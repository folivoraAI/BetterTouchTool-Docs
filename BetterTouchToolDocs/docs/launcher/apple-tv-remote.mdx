# Apple TV Remote in the Launcher

The Launcher can act as a remote control for Apple TV (and other devices that speak the same protocol). This is a rich surface: selecting the **Apple TV Remote** row expands the Launcher into a full on-screen remote.

## Opening the Remote

Select the **Apple TV Remote** row and press `↩`. It lives in the **Widgets** group by default, so you can also reach it quickly by assigning a shortcut to that group.

## Using the Remote

The surface renders a native on-screen remote with:

- Directional pad (up/down/left/right + select)
- Menu / Back button
- Home button
- Play/pause and skip controls
- Volume / sleep / Siri (where supported by the target device)

Clicking a button sends the command to the paired device. You can also use your keyboard — arrow keys for the d-pad, `↩` for select, `Esc` to leave the surface.

## Pairing

The first time you open the remote you'll be asked to pair with a device. The pairing flow matches how you pair a physical Apple TV remote: enter the PIN shown on the Apple TV screen, and the pairing persists across Launcher restarts.

## Keeping it Open

If you want the Launcher to stay up while you use the remote, click the **pin** icon in the top right of the Launcher window. This prevents clicks outside the window from closing it.

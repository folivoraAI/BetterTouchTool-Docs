# Configured Triggers in the Launcher

Any trigger you configure in BetterTouchTool (a hotkey, trackpad gesture, Stream Deck button, named trigger, menubar item, etc.) can also appear as a searchable item in the Launcher.

This is how you turn BetterTouchTool into a command palette for your own automations.

## Enabling "Show in Launcher"

Open the configuration of any BTT trigger and look for the **Launcher** section in the right-hand configuration panel. It offers:

- **Show in Launcher** — the master on/off switch. When enabled, the trigger becomes a Launcher entry.
- **Title** — the name shown in the Launcher. If empty, BetterTouchTool derives a title from the action.
- **Details** — subtitle shown under the title.
- **Icon** — choose an SF Symbol, emoji, or custom image via the standard BTT icon configuration.

Once you save the trigger, it shows up in the Launcher's configured-triggers section and can be searched by its title or by any aliases you give it (see [Customization](./customization)).

## Running the Trigger

Searching for a configured trigger and pressing `↩` in the Launcher runs the full trigger — the entire action chain, including conditions, variables, scripts, and all.

Because it runs through the normal BTT trigger pipeline:

- Conditions you added still apply.
- Scripts still execute in the same context.
- Variables are still updated.

## Organizing Configured Triggers

Configured triggers participate in the normal Launcher ranking and customization:

- Add **aliases** so `invoice` finds a trigger titled "Create Invoice Number".
- Adjust **priority** (`Increase/Decrease Priority` in the per-item popover) to boost triggers you use often.
- **Pin** a trigger to get a quick pill above the results.
- Dynamically loaded triggers are inserted into the results under the default "Dynamically loaded BTT Triggers" section position; you can reorder and group them the same way as other sections.

## Per-Trigger Multiple Launcher Entries

Advanced: a single trigger can expose multiple distinct Launcher entries with different titles, icons, and sort order. This is useful when one action should be discoverable under several names or in several contexts. See the Launcher settings for a trigger's entry list.

# Built-In Items & Sections

The Launcher ships with a catalogue of built-in sections. Each one can be enabled/disabled, reordered, assigned to a group (folder), and renamed in the Launcher settings sheet (reachable from the Launcher's menu button in the top-left corner of the window).

## Built-In Sections

All built-in sections are **enabled by default**.

| Section | Default Order | Default Group | What it does |
| --- | --- | --- | --- |
| Finder Context | −10000 | — | Shows the current Finder selection or frontmost folder when Finder is active; includes "Open With…" children. |
| Clipboard Manager | 1000 | — | Single entry that opens the full clipboard surface. See [Clipboard](./clipboard). |
| Calendar | 1500 | Widgets | Entry that opens the calendar surface. See [Calendar](./calendar). |
| Apple TV Remote | 2000 | Widgets | Opens an on-screen remote. See [Apple TV Remote](./apple-tv-remote). |
| Launcher Plugins | 2500 | — | Entries contributed by installed Launcher plugins. |
| BetterTouchTool Actions | 3250 | Commands | Browse and execute any predefined BTT action. See [BTT Actions](./btt-actions). |
| Start Dictation | 3000 | Commands | Opens the speech dictation surface. See [Speech Dictation](./speech-dictation). |
| Running Apps | 4000 | Apps | Apps that are currently running; `Tab` lists their open windows. |
| Installed Apps | 5000 | Apps | All installed applications on disk. |
| File Search | 5500 | — | Indexed file name search (triggered with a leading space or the `file` keyword). |
| File Browser | 5750 | — | Finder-like browser surface. See [Files](./files). |
| AI Chat Conversations | 8000 | AI | Recent h@llo.AI conversations. |

A lower order number means the section appears earlier in the results list.

In addition, the following are always available but not managed as separate built-in sections:

- **URL input** — type a URL and press `↩` to open it.
- **Math** — type a calculation (e.g. `37*19+4`) and the result appears at the top of the list with `Copy` on `↩`.
- **Configured Triggers** — any of your BTT triggers that have "Show in Launcher" enabled. See [Configured Triggers](./configured-triggers).
- **Floating Menu embeds** — floating menus with a Launcher embedding mode can appear inline in results.

## Built-In Groups (Folders)

Groups let you collapse related built-in items into a single browsable folder when the search field is empty. While you are searching, results appear flat so matches never hide inside a folder.

| Group | Default Order | Icon |
| --- | --- | --- |
| Widgets | 1500 | `square.grid.2x2` |
| Commands | 3000 | `command.circle` |
| AI | 3500 | `sparkles` |
| Apps | 4000 | `app.connected.to.app.below.fill` |

In the Launcher settings you can:

- Rename a group.
- Change its SF Symbol icon.
- Reorder groups.
- Assign a **keyboard shortcut** to jump directly to it from the main results list.
- Move any built-in item into or out of a group.

## Finder Context

When Finder is the frontmost app, the Launcher automatically shows a Finder Context row at the top:

- If there is a Finder selection, it shows the selected file or folder.
- Otherwise it shows the current Finder folder as the context.

Pressing `↩` opens the item. `Tab` opens an **Open With…** sublist so you can pick a specific app.

## Apps

The Launcher maintains its own app index covering:

- `/Applications`
- `/System/Applications`
- `/System/Library/CoreServices`
- macOS cryptex / system app roots
- `~/Applications`

App results are ordered as:

1. **Recent apps** — apps you recently activated from the Launcher.
2. **Running apps** — apps that are currently running.
3. **All other installed apps**.

Running apps that have more than one window advertise a child list (the built-in window switcher). Press `Tab` or `→` on a running app row to see its open windows, with live thumbnails and on-screen highlight previews.

## File Search

File Search is accessible by:

- Typing a **leading space** followed by the filename (e.g. ` report.pdf`), or
- Entering the configured file-search keyword (default: `file`), then a space, then your query.

You can configure additional keywords and search scopes in the Launcher settings.

## Math

Type any basic arithmetic expression into the search field. When the expression parses, a math row appears at the top of the list:

- `↩` copies the result to the clipboard.

## URL

Type a URL (e.g. `github.com/foo/bar`) and press `↩` to open it in your default browser.

# Running BetterTouchTool Actions from the Launcher

Every predefined BTT action is searchable and executable directly from the Launcher. This is different from [Configured Triggers](./configured-triggers): it exposes the raw action catalogue, not your own saved triggers.

## Opening the Actions Surface

In the main results list, type the name of an action (e.g. `paste custom text`, `volume up`, `show desktop`) and press `↩`.

Alternatively, select the top-level **BetterTouchTool Actions** entry to open the actions browser — a rich surface that lets you drill through all predefined actions hierarchically.

By default this section lives in the **Commands** group, so it's reachable by the group's keyboard shortcut once you've set one.

## Browsing and Running

- Actions are organized hierarchically (e.g. *Window Actions → Move Window*).
- Type to filter; the list narrows as you type.
- `↩` on an action runs it immediately.
- `Tab` or `→` drills into a subcategory.
- `←` goes back one level.

Some actions require configuration (for example, a keyboard shortcut to send). For complex actions that need per-call configuration, the Launcher uses sensible defaults — create a named trigger in BTT if you need custom parameters, then expose it via [Configured Triggers](./configured-triggers).

## When to Use This vs. Configured Triggers

- Use the **BTT Actions surface** for one-off execution or exploration of the action catalogue.
- Use **Configured Triggers** when you want an action with specific parameters (custom text, a particular keyboard shortcut, scripts, etc.) to be reachable by name in the Launcher.

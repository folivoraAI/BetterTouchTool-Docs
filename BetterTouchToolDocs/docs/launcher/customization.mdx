# Customizing Launcher Results

The Launcher lets you tailor its behavior per row, per section, and per Launcher instance. Everything on this page is accessible **without writing code** — all via the per-item actions popover (`⌘P`) or the Launcher settings sheet.

## Aliases (Keywords)

Aliases are extra search terms that let a row match queries that don't appear in its title. For example, you can make a running-apps row for Safari match the term `browser`, or a configured trigger titled "Daily Standup Notes" match the alias `stnd`.

To set aliases:

1. Select the row in the Launcher.
2. Press `⌘P` to open the per-item actions popover.
3. Choose **Set Keywords…**.
4. Enter comma-separated terms.

Ranking rules:

- Exact alias matches rank above title-prefix matches.
- Aliases stack with the built-in searchable fields.
- Aliases are remembered per Launcher instance when you edit them from the "Set Keywords for This Launcher…" entry, or globally via "Set Global Keywords…".

Aliases work at every level of the Launcher, including inside child lists like an app's windows.

## Filter Priority

Every row has a priority that affects its ranking *in filtered searches*. Use this when two items always compete for the top spot and you always want one specific item to win.

Available from the per-item popover:

- **Increase Priority**
- **Decrease Priority**
- **Reset Priority**

Priority overrides do not reorder the unfiltered browsing list — use built-in section order for that.

## Pinning

Pin a row to keep a quick-access pill at the top of the Launcher window.

- Pin: open the per-item popover and select **Pin**.
- Unpin: right-click the pill, or select **Unpin** from the per-item popover.
- Drag a pill to reorder pinned items.
- Click a pill to activate the pinned item immediately.

Apps, clipboard, calendar, Apple TV remote, and other built-in items can all be pinned.

## Hiding Items

Some sections, like configured triggers, can be hidden globally from the Launcher via the per-item popover's **Hide From Launcher** command without deleting the underlying trigger. Hidden items don't appear in any search results but remain configured in BTT.

## Section Order and Enable State

Open the Launcher settings (via the menu button in the top-left corner of the Launcher) to:

- Enable / disable each built-in section.
- Reorder sections by dragging them.
- Move a built-in section into a group (folder), or remove it from its group.
- Reorder groups themselves.
- Change group titles and icons.
- Assign keyboard shortcuts to groups.

See [Built-In Items](./built-in-items) for the list of sections and their defaults.

## Smart Ranking (Query Memory)

The Launcher remembers which result you picked for each query. Next time you type the same query, your previous pick ranks higher. This is automatic — there's nothing to configure.

Query memory is stored per Launcher instance, so two Launchers with different IDs (see [Multiple Launchers](./multiple-launchers)) maintain independent memory.

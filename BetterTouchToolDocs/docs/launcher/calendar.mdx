# Calendar in the Launcher

The Calendar surface lets you browse your macOS calendars, inspect upcoming events, and create new events and reminders — all without leaving the Launcher.

The Calendar uses the system `EventKit` framework, so it shows the same calendars and reminder lists you see in Apple's Calendar and Reminders apps. You'll be asked for calendar and reminders access the first time you open it.

## Opening the Calendar

- Type `calendar` (or an alias you configured) and press `↩`.
- Or select the **Calendar** row and activate it.
- In the Launcher settings you can also assign it to the **Widgets** group and give the group its own shortcut for direct access.

## Browsing

Once inside:

- Arrow keys move through dates.
- Switch between month / week / day views from the controls in the header.
- Events and reminders are displayed inline; selecting one shows detail.

## Creating Events and Reminders

Two quick commands are available on the Calendar row in the main results:

| Command | Shortcut | Effect |
| --- | --- | --- |
| Create New Event | `⌘N` | Opens the event composer inside the surface. |
| Create New Reminder | `⌘⇧N` | Opens the reminder composer. |

Inside the composer you can set title, time, calendar, notes, and (for reminders) due date and priority.

## Returning to Results

Press `Esc` to leave the Calendar surface. The Launcher restores its previous size and returns to the results list with your previous selection preserved.

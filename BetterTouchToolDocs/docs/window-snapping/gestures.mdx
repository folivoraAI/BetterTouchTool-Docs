# Snap using Triggers

BetterTouchTool offers an extensive set of actions that allow you to move & resize windows. By assigning these actions to some custom triggers (e.g. keyboard shortcuts or trackpad gestures) you can create nice workflows easily.

![preferences4](/media/new/snaptrigger.jpg)


In case the default sizes / positions don't work for you, there is also a predefined action called **Custom Move/Resize**, which allows you to resize and move windows to completely customizable positions.

You can also assign these window actions to items in a [snapping menu](/docs/window-snapping/snapping-menus#customize-a-menu), where they run against the window you are dragging. The additional actions whose names end in **(Snap Menu)** use the current snapping position and only work from a snapping menu; use the standard window actions for ordinary keyboard shortcuts or gestures.

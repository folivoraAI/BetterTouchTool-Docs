# Getting Started

1. Add the predefined action **h@llo.ai - Show Customizable AI Assistant** to any BetterTouchTool trigger.
2. Choose an AI backend in the assistant configuration and add the required API key, login, local server URL, or CLI setup.
3. Open **AI Configuration -> Tools & Context -> Manage Skills...**.
4. Enable the skills that match the assistant's job.
5. Trigger the assistant and start with a small request.

## Good First Setup

For a general BTT helper, enable:

- **General Assistant**
- **BTT Expert**

Then ask something simple, for example:

```text
Create a keyboard shortcut that shows a HUD saying "Hello".
```

Once that works, add more focused skills such as **Computer Use**, **Background Computer Use**, **Research Assistant**, or **Floating Menu & Widget Creator**.

## Keep It Focused

Create separate assistants for separate jobs. A small assistant with two relevant skills is usually faster, safer, and more reliable than one assistant with every possible capability.

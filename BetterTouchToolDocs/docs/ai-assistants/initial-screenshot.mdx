# Initial Screenshot Or Message

An assistant action can start with a predefined user message, a screenshot, or both. This is useful when a trigger should immediately ask the assistant to process something without waiting for manual input.

Examples:

- capture a selected screen region and ask the assistant to describe it
- send the current clipboard text for summarization
- run a fixed prompt whenever a Stream Deck button is pressed
- attach a screenshot before a computer-use task starts

For repeated background tasks, also see [Usage Without UI](./usage-without-ui).

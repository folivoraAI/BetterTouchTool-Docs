# Embedding Floating Menus

An AI Assistant can embed a BetterTouchTool floating menu inside the chat. This is helpful when the assistant is used for repeated workflows that benefit from fixed buttons, toggles, or status widgets.

![Embedded floating menu](/media/embedding-floating-menus2026-04-30T09:25:50.639Z.png)

Recommended setup for the embedded menu:

- Set availability to **Only Embedded**.
- Give the menu an explicit size, or use fit-to-content if the layout is simple.
- Keep controls compact and task-focused.

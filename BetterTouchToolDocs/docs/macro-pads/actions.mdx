# Macro Pad Actions

These actions can be assigned to any trigger — a keyboard shortcut, a gesture, or
an item on the pad itself. You'll find them in the **Macro Pad Actions** group when
choosing an action.

## Switching what a pad shows

- **Macro Pad: Show Menu** — points a pad at a different Floating Menu, by name or
  UUID. Leave the name empty to send the pad back to the menu it is bound to.
- **Open Specific Submenu in Floating Menu** — opens a submenu. This also works for
  on-screen menus, so one action covers both.
- **Floating Menu: Close Submenu** — leaves the current submenu.
- **Macro Pad: Next Page / Previous Page** — page navigation.

Together these replace the older *Open / Close Stream Deck Group* triggers.

## Display and power

- **Macro Pad: Set Brightness** and **Macro Pad: Change Brightness**
- **Macro Pad: Turn On**, **Turn Off** and **Toggle On/Off**

These work with Elgato Stream Decks as well as AJAZZ/Mirabox and Loupedeck/Razer
pads.

## Choosing which device is affected

Actions that can target a device have a field for a serial number. Leave it empty
to affect **every** macro pad driven by a Floating Menu, or enter a serial to affect
one. The currently connected pads and their serial numbers are listed below the
field, so you can copy the right one.

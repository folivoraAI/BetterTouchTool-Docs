# BTT Mobile (New App, 2026)

You need to enable BTT Mobile manually once. Open the BetterTouchTool settings, then enable the BTT Mobile app (only the new one is required)

Also make sure BetterTouchTool on macOS is allowed in System Settings => Security & Privacy => Local Network, otherwise you'll not be able to connect!
